# Как ведётся работа

Общий порядок — в уставе студии
([`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md)):
документы в репозитории, спецификация до кода, ADR, ветки `claude/…`, PR, CI на PR. Особенности ПК-игры — как у
«Больницы» (её `docs/05-process.md`); здесь — только то, что своё.

## Ветки, слияние, CI

- Работа — в ветках `claude/<задача>`, в `main` — через PR. Кто сливает — по классам изменений (ADR студии
  [0018](https://github.com/Nefeste/gornitsa/blob/main/adr/0018-change-classes-automerge.md)); пути владельца — в
  [`.github/CODEOWNERS`](../.github/CODEOWNERS).
- Части прототипа идут PR одна за другой. Пока предыдущая не слита, следующая открывается поверх её ветки и потом
  перецеливается на `main`.
- Проверки на PR (`pr.yml`, ADR студии [0019](https://github.com/Nefeste/gornitsa/blob/main/adr/0019-ci-on-pr.md)):
  сборка и валидатор базы, типы, тесты, сборка страницы — те же команды, что в `AGENTS.md` («Commands»). Electron там не
  скачивается. Bun в CI — 1.3.11, как у «Больницы»; тесты проходят и на нём, и на 1.4.
- Сборка для ПК — только на тег версии `vX.Y.Z` ([`.github/workflows/build.yml`](../.github/workflows/build.yml)):
  Windows x64 одним zip, из Linux, без wine, как у «Больницы». Тег ставит владелец; тег сверяется с версией в
  `package.json`. Файл релиза — `Farmzavod-<версия>-win-x64.zip`; `Farmzavod` — рабочее имя файлов, марку решит
  владелец.

## Сборка у себя

```bash
npm ci                 # с Electron; для одних проверок — ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci
npm run build          # база + страница и поток расчёта → dist/
npm run electron       # окно игры
npm run dist:win       # zip для Windows x64 → release/ (из Linux, без wine) — то же, что в релизе
```

`dist/`, `release/` и `src/content/generated/` в репозиторий не попадают.

## Копии из «Больницы»

Платформа переносится копированием (ADR студии 0002, ADR проекта [0002](adr/0002-stack.md)) с пометкой источника и
коммита в первой строке: `// из bolnitsa: <путь> @ <коммит>` и, если менялось, — что изменено. Файл, который сама
«Больница» взяла из «Анамнеза» и не меняла, сохраняет свою строку `// из anamnez: …`: поиск по ней находит все копии.
Исправление в скопированном — задача перенести его и в «Больницу».

## Версии

По уставу. Сборки прототипа — `0.0.x`, по одной на часть: что в каждой — в разделе версий корневого
[`README.md`](../README.md). Первая версия для игры владельца — `0.1.0`. Номер живёт в `package.json` и
`package-lock.json`; тест проекта сверяет их (`tools/test/version.test.ts`).
