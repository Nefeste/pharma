## Планки качества

Каждый этап после прототипа отвечает не только «что сделано», но и «на каком уровне». Планка — то, что получает
игрок; проверка — чем мы это измеряем. Планка этапа не снижается ради срока: срок двигается.

| Планка | Что значит | Чем проверяется |
|---|---|---|
| Понятно без документов | новичок за полчаса понимает, почему линия стоит и чего ждёт серия, не открывая справочник | игра человека, не читавшего документов; вопросы спецификации прототипа |
| Правда вещи | на экране ровно то, что в учёте: короба, статусы, накопители, маршруты | тесты «правда вещи» ([`13-art.md`](13-art.md), §17) |
| Читаемо | статусы и состояния различимы с высоты цеха, на низком пресете и при цветовой слепоте | контактный лист и имитация цветовой слепоты в проверках |
| Держит удар | завод живёт годами на 20 зёрнах без сбоев и потерь сохранений | «виртуальный директор» ([`02-architecture.md`](02-architecture.md), §15) |
| Честные факты | у каждой механики — источник, каждая запись с фактами проверена человеком | `review: checked` владельца; сборка базы |
| Два языка — одно качество | русский и английский без переполнений и без «английского по остаточному принципу» | тест переполнения карточек; вычитка |
| Идёт на целевом ПК | цели геймдизайна (§21) на ПК владельца и на опорном ноутбуке | авто-бенч по тегу |

## После 1.0

Порядок — по решениям владельца 17–18.10.2026 ([#11](https://github.com/Nefeste/pharma/issues/11),
[#9](https://github.com/Nefeste/pharma/issues/9), [#23](https://github.com/Nefeste/pharma/issues/23), [#31](https://github.com/Nefeste/pharma/issues/31)); что ещё отложено — геймдизайн, §25.

1. **Саше** (порошки и гранулы) и **суппозитории** — новые линии, материалы и испытания.
2. **Жидкие формы:** суспензии для приёма внутрь, сиропы, капли, спреи, растворы и гели для приёма внутрь и для
   местного применения.
3. **Экспорт: профиль GMP ЕС, затем FDA (США)** — акт кампании «Экспорт» (геймдизайн, §27), после жидких форм.
   В 1.0 профиль один — ЕАЭС. Второй профиль — повод пересмотреть ADR [0004](adr/0004-regulatory-profile.md) по
   его же условию; факты каждого профиля — в `10-domain.md` до спецификации.
4. Стерильные формы, этажи и площадки, Мастерская Steam и моды, Steam Deck, другие языки. План здания с Б7 хранит
   номер этажа, чтобы этаж добавился без поломки сохранений (решение владельца 21.10.2026,
   [#82](https://github.com/Nefeste/pharma/issues/82)).
5. **«Свой завод»** — данные настоящего предприятия: владелец решит по итогам игры в прототип
   ([#14](https://github.com/Nefeste/pharma/issues/14)); без онлайн-коннектора, завод из файлов — цель (решение владельца
   20.10.2026, [#70](https://github.com/Nefeste/pharma/issues/70)); шаги — в [наброске](specs/2026-10-own-plant.md).
6. **Игра вдвоём** — по очереди за одним компьютером, эстафетой сохранения или по сети (для сети — новый ADR вместо ADR
   [0001](adr/0001-studio-adrs.md)): решаем после 1.0 ([#31](https://github.com/Nefeste/pharma/issues/31); геймдизайн,
   §29.6).
