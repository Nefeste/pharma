# Документация «Фармзавода»

Здесь лежит всё, что нужно, чтобы продолжать работу над проектом, ничего не помня о нём
заранее. Устройство — по уставу студии (`docs/04-process.md`), номера документов — те же, что в
остальных играх. Код — прототип, его состояние — в `STATUS.md`. ADR 0001–0004 утверждены владельцем
17.10.2026 ([#13](https://github.com/Nefeste/pharma/issues/13)); направление замысла — обещание, чувства, столпы,
картинка и звук, планки качества — 18.10.2026 ([#22](https://github.com/Nefeste/pharma/issues/22)). Остальное в продукте и геймдизайне документы описывают
как принятый замысел с пометкой «предложение», пока владелец его не утвердил.

Состояние — [`STATUS.md`](../STATUS.md) в корне; этапы, планки качества и решения владельца —
[`07-roadmap.md`](07-roadmap.md).
Открытые вопросы владельцу и развилки — только в Issues: метки [`владелец`](https://github.com/Nefeste/pharma/issues?q=is%3Aissue+is%3Aopen+label%3A%D0%B2%D0%BB%D0%B0%D0%B4%D0%B5%D0%BB%D0%B5%D1%86) и
[`развилка`](https://github.com/Nefeste/pharma/issues?q=is%3Aissue+is%3Aopen+label%3A%D1%80%D0%B0%D0%B7%D0%B2%D0%B8%D0%BB%D0%BA%D0%B0).

## Сестринский проект

«Больница» (`Nefeste/bolnitsa`) — первая ПК-игра студии. Её платформа переносится сюда
копией (ADR [0002](adr/0002-stack.md)); её документы — образец для устройства окна, потока
расчёта, стройки и людей, и здесь они не пересказываются.
