# Документация «Фармзавода»

Здесь лежит всё, что нужно, чтобы продолжать работу над проектом, ничего не помня о нём
заранее. Устройство — по уставу студии (`docs/04-process.md`), номера документов — те же, что в
остальных играх. Код — каркас прототипа (часть 0); остальное документы описывают как принятый замысел с пометкой
«предложение», пока владелец его не утвердил.

Состояние — [`STATUS.md`](../STATUS.md) в корне; план и вопросы владельцу —
[`07-roadmap.md`](07-roadmap.md).

## Порядок чтения

1. [`01-product.md`](01-product.md) — что за игра: три чувства, столпы, две высоты, для кого,
   цифровой двойник, проверка по обещаниям студии, чего нет сознательно, словарь.
2. [`08-game-design.md`](08-game-design.md) — геймдизайн 1.0: время, стройка, склад,
   производство, качество и расследование, техслужба, персонал, планирование, рынок, закупки,
   деньги, портфель, режимы, экраны, картинка. **Все числа геймдизайна — только там.**
3. [`10-domain.md`](10-domain.md) — как устроен настоящий завод: факты, на которых держатся
   механики, с источниками и отметкой «сверить».
4. [`02-architecture.md`](02-architecture.md) — как устроена игра: платформа «Больницы»,
   модули движка, время и поток, детерминизм, окно и 3D, прогон плана, данные, проверки.
5. [`04-data-model.md`](04-data-model.md) — записи базы, сущности состояния, статусы,
   прослеживаемость, примеры YAML.
6. [`specs/2026-10-prototype.md`](specs/2026-10-prototype.md) — что должен показать прототип.
7. [`07-roadmap.md`](07-roadmap.md) — этапы и вопросы владельцу.
8. [`09-market.md`](09-market.md) — фармацевтические игры в Steam и ориентиры жанра.
9. [`adr/`](adr/README.md) — решения, которые дорого менять; первым — какие ADR студии
   действуют здесь.
10. [`journal/`](journal/) — журнал по месяцам.

Как ведётся работа и собирается игра — [`05-process.md`](05-process.md); что проверяется — [`06-testing.md`](06-testing.md).

## Сестринский проект

«Больница» (`Nefeste/bolnitsa`) — первая ПК-игра студии. Её платформа переносится сюда
копией (ADR [0002](adr/0002-stack.md)); её документы — образец для устройства окна, потока
расчёта, стройки и людей, и здесь они не пересказываются.
