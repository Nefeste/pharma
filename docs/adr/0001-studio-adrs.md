# 0001. ADR студии во второй ПК-игре: что действует, что нет, от чего отступаем

**Предложение**, действует после утверждения владельцем.

**Решили.** «Фармзавод» — проект студии «Горница» для ПК. Марку выбирает владелец;
предположение — та же отдельная марка, что у «Больницы» (решение владельца №81 в
`Nefeste/uprava`). Устав действует целиком, кроме мест, где он говорит о телефонах и RuStore.
Таблица повторяет решения «Больницы» (её `docs/adr/0001-studio-adrs.md`), потому что
положение то же; отличия выделены.

| ADR студии | Здесь |
|---|---|
| 0001 устав в одном репозитории | действует |
| 0002 копирование вместо общего пакета | действует: платформа «Больницы» — копиями с пометкой источника ([0002](0002-stack.md)) |
| 0003 Expo / React Native, APK в CI | **не действует.** Для ПК-игр — ADR студии 0021; здесь — [0002](0002-stack.md) |
| 0004 чистый движок, снимки, вечные идентификаторы | действует |
| 0005 без сети по умолчанию, свой сервер | действует строже: сети нет совсем, сервера нет |
| 0006 вечный идентификатор и ключ подписи Android | не относится; для ПК — идентификатор игры в Steam и подпись, решение — до страницы Steam (как у «Больницы») |
| 0007 ключ устройства без учётных записей | не относится: нет сервера |
| 0008 минимум данных | действует: игра ничего не отправляет |
| 0009 деньги: RuStore Pay на телефоне | **не действует.** Игра продаётся в Steam целиком; ADR о деньгах — общий с «Больницей», до страницы Steam |
| 0010 без давления | действует; пауза — в любой момент; сроки заказов и тендеров — часть мира игры, а не реальное время |
| 0011 честная игра с людьми | не относится: игра одиночная. Дух решения держим: случайность от зерна, шансы показаны (`01-product.md`, столп 5) |
| 0012 контент из источников | **факты о производстве — действует полностью**: стадии, нормы, испытания и требования — из названных источников с `review`, проверка — человек-консультант ([0004](0004-regulatory-profile.md)); графика — исключение по ADR студии 0020 |
| 0013 «Сени» | действует, когда появится почта поддержки марки |
| 0014 два региона | действует: игроки по всему миру, но ничего не уходит с компьютера игрока |
| 0015 страница игры на сайте студии | решит владелец вместе с маркой |
| 0016 профиль с 14 лет | не относится: профиля на сервере нет |
| 0017 видимость | действует: репозиторий закрыт |
| 0018 классы изменений, автослияние | действует |
| 0019 CI на PR, сборка на тег | действует: проверки на PR — с первым кодом; сборка ПК-версии — на тег |
| 0020 генераторы графики в ПК-играх | действует: журнал генераций, одобрение владельца, честная анкета Steam; оборудование по возможности — моделями кодом (`08-game-design.md`, §19.4) |
| 0021 ПК-стек | действует ([0002](0002-stack.md)) |

**Почему.** Вторая ПК-игра не должна молча выпадать из правил студии. Всё, что не про
телефон, остаётся в силе, а каждое отступление записано.

**Платим.** Решения о деньгах в Steam, подписи и связи с клиентом Steam общие с «Больницей»:
«Фармзавод» ждёт их, а не принимает свои.

**Когда пересмотреть.** Когда владелец выберет марку (№85) и примет ADR о деньгах в Steam.
