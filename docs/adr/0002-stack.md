# 0002. Стек — как у «Больницы»: TypeScript, Electron, Three.js; платформа — копией; расчёт — в отдельном потоке

**Предложение**, действует после утверждения владельцем. Применяет ADR студии 0021
(ПК-игры: TypeScript, Electron, Three.js) и 0002 (копирование вместо общего пакета).

**Решили.**

- **Язык — TypeScript** везде: движок, интерфейс, инструменты, тесты (Bun, как у «Больницы»).
- **Платформа «Больницы» переносится копией** с пометкой источника в первой строке файла
  (`// из bolnitsa: <путь> @ <коммит>`): ядро движка (зерно, очередь, целочисленная
  математика), стройка мышью, люди и найм, поток расчёта с упакованным срезом, окно Electron
  без сети, 3D-основа (полы, стены со срезом, свет, толпа), хранилище панелей, сборка базы,
  сценарий в браузере, бенчи. Список — `docs/02-architecture.md`, §2.
- **Окно и сборка — Electron**, сборка из Linux по тегу. В релиз — то же, что у «Больницы»
  на день выпуска (сейчас — Windows x64 одним zip, решение владельца №95).
- **Вид — 3D на Three.js**, изометрия как у «Больницы». Оборудование, тара, паллеты и
  техника — по возможности **моделями кодом** из описаний в данных.
- **Расчёт — в отдельном потоке** (Web Worker), отрисовка — в основном. Прогон плана — во
  втором потоке расчёта.

**Почему.**

- Стек проверен пробами «Больницы» 16.10.2026 на ПК владельца: 60 к/с при сотнях
  анимированных людей, процессор на кадр — меньше 1 мс (ADR «Больницы» 0002).
- Половина систем у двух игр общая: стройка, люди, смены, время, 3D, окно. Копия экономит
  месяцы, а агенты переходят между проектами без переучивания.
- Модели кодом держат один стиль без художника. Фармацевтическое оборудование — в основном
  корпуса, кожухи и роторы, а генераторы 3D слабы в мелкой механике (отчёт «Больницы»
  `docs/reports/2026-10-3d-generators.md`).

**Платим.**

- Electron тяжёлый (90–140 МБ сборки, полгигабайта памяти); WebGL не даёт фотореализма — как
  у «Больницы».
- Исправление в скопированном коде нужно переносить в обе стороны. Платформу придётся
  сверять с «Больницей» по строке-источнику.
- Модели кодом — работа программиста и агентов, а не художника. Их вид проверяет владелец
  на снимках.

**Когда пересмотреть.** Вместе с ADR «Больницы» 0002 — по тем же условиям. Ещё — если
студия заведёт общий пакет платформы для ПК-игр в `gornitsa-kit`.
