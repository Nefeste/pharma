# Решения проекта (ADR)

Короткие записки о решениях, которые дорого менять: что решили, почему, чем платим, когда
пересмотреть. Порядок — как в уставе студии (`adr/README.md` устава). Читать **до** того, как
предлагать обратное.

Все четыре записки написаны агентом 17.10.2026 и **утверждены владельцем** в тот же день
([#13](https://github.com/Nefeste/pharma/issues/13): «Утвердить все четыре ADR»); строка
состояния в начале каждой записки это говорит. Решения владельца, принятые после них, —
[`../07-roadmap.md`](../07-roadmap.md), «Решения владельца»; по условию ADR 0004 второй регуляторный
профиль (экспорт после 1.0) — повод его пересмотреть.
